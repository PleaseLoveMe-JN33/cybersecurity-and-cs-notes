### 1.1   掌握字面量的含义

什么是字面量 ？

在代码中，直接写出来的、表示某个**固定值的东西**

python中常用的值类型如下

**数字（Number）**

整数（int），如10和 -10

浮点数（float），如13.14

复数（complex），如4 + 3j，以j结尾表示复数

布尔（bool）表达现实生活中的逻辑，即真和假，True（1）为真，False（0）为假

**字符串（string）**

描述文本的一种数据类型，由任意数量的字符组成

**被双引号包围起来的，就是字符串**

**列表（List）**

有序的可变序列，python中用的最频繁的数据类型，可以有序记录一堆数据

**元组（Tuple）**

有序的不可变序列，可以有序的记录一堆不可变的python数据集合

**集合（Set）**

无序不重复集合，可无序记录一堆不重复的python数据集合

**字典（Dictionary）**

无序Key-Value集合，可无序记录一堆Key-Value型的python数据集合

#### **1.5.3   格式化的精度控制**

先看代码演示

```
# 代码
name = "JohnWang"
age = 23
stature = 178.45
message = "我的名字是%s,我今年%d岁了，我的身高是%fcm" % (name, age, stature)
print(message)

# 编译结果
我的名字是JohnWang,我今年23岁了，我的身高是178.450000cm
```

Q：为什么浮点数178.45，变成了178.450000输出 ？

A：未进行数字精度的控制

**OK，那怎么进行精度的控制呢 ？**

使用辅助符号 "m.n" 来控制数据的宽度和精度

-  **m**，控制宽度，用数字填写，设置的宽度小于数字本身时不生效
- **.n**，控制小数点精度，用数字填写，会进行小数的四舍五入

举个例子来看

```
# 代码
name = "JohnWang"
age = 23
stature = 178.46
message = "我的名字是%s,我今年%5d岁了，我的身高是%.1fcm" % (name, age, stature)
print(message)

# 编译结果
我的名字是JohnWang,我今年   23岁了，我的身高是178.5cm
```

### 5.7   数据容器（序列）的切片

序列的概念：内容连续，有序，可使用下标索引的一类数据容器

**列表，元组，字符串**都可视为序列

切片：从一个序列中，取出一个子序列

**语法：序列[起始下标:结束下标:步长]**

- 起始下标，表示从何处开始，留空的话意味从头开始
- 结束下标，表示何处结束，**假如为5，则意为到5结束但不包括5**，留空意味一直到结尾
- 步长表示依次取元素的间隔
- 步长1，一个个取元素
- 步长2，每次跳1个取元素，以此类推
- 步长为负，反向取

**切片操作不会影响序列本身，只会得到一个新的序列**

### 8.1   了解异常

Q：什么是异常？

A：当检测到一个错误时，Python解释器就无法继续执行，出现了一些错误的提示，这就是所谓的异常，也就是我们常说的BUG

> bug单词的诞生
>
> 早期计算机采用大量继电器工作，马克二型计算机就是这样的
>
> 1945年9月9日，下午三点，马克二型计算机无法正常工作了，技术人员试了很多办法，最后定位到第70号继电器出错，负责人哈珀观察这个出错的继电器，发现一只飞蛾躺在中间，已经被继电器打死，她小心地用镊子将蛾子夹出来，用透明胶布贴到“事件记录本”中，并注明 “ 第一个发现虫子的实例 ”
>
> 自此之后，引发软件失效的缺陷，便被称为Bug

### 8.2   异常的捕获方法

Q：为什么要捕获异常？

A：世界上没有完美的程序，任何程序在运行的过程中，都有可能出现异常，我们要做的，不是力求程序完美运行，而是在力所能及的范围内，对可能出现的bug，进行提前准备、提前处理

当我们的程序遇到了BUG，那么接下来有两种情况：

1. 整个程序因为一个BUG停止运行
2. 对BUG进行提醒，整个程序继续运行

在真实工作中，我们肯定不能因为一个小的BUG就让整个程序全部奔溃，也就是我们希望的是达到2这种情况

捕获异常的作用在于，提前假设某处会出现异常，做好提前准备，当真的出现异常的时候，可以有后续手段

- 基本语法：

```
try:
    可能发生错误的代码
except:
    如果出现异常执行的代码
```

- 捕获指定异常：

```
try:
    print(name)
except NameError as e:
    print('name变量名称未定义错误')
```

注意事项：

1. 如果尝试执行的代码的异常类型和要捕获的异常类型不一致，则无法捕获异常
2. 一般try下方只放一行尝试执行的代码

- 捕获多个异常：

```
try:
    print(1/0)
except (NameError, ZeroDivisionError):
    print('出现了变量未定义 或者 除以0的异常错误')
```

- 捕获所有异常：

```
try:
    f = open("D:/123.txt", "r")
except Exception as e:
    print("出现异常了")
```

**图省事可以把Exception as e删掉**

- 异常的else：

```
try:
    print(1)
except Exception as e:
    print(e)
else:
    print('我是else，是没有异常的时候执行的代码')
```

- 异常的finally

finally表示的是无论是否异常都要执行的代码，例如关闭文件

```
try:
    f = open('test.txt', 'r')
except Exception as e:
    f = open('test.txt', 'w')
else:
    print('没有异常，真开心')
finally:
    f.close()
```

### 8.3   异常的传递

```
def func01():  # 异常在func01中没有被捕获
    print("这是func01开始")
    num = 1 / 0
    print("这是func01结束")

def func02():  # 异常在func02中没有被捕获
    print("这是func02开始")
    func01()
    print("这是func02结束")

def main():  # 异常在mian中被捕获
    try:
        func02()
    except Exception as e:
        print(e)

main()

# 编译结果
这是func02开始
这是func01开始
division by zero
```

上图的示例说明了，**异常是具有传递性的**

当函数func01中发生异常，并且没有捕获处理这个异常的时候，异常会传递到函数func02，当func02也没有捕获处理这个异常的时候main函数会捕获这个异常， 这就是异常的传递性

```
    __is_5g_enable = False  # 题目要求运行结果是关闭，所以这里初始值设为 False

    def __check_5g(self):
        if self.__is_5g_enable == True:

    def call_by_5g(self):

        print('正在通话中')
```

pass关键字，一个普通的占位语句

- 复写

子类继承父类的成员属性和成员方法后，如果对其不满意，那么可以进行复写，即在子类中重新定义同名的属性或方法即可

```
class Phone:
    IMEI = None              # 序列号
    producer = "ITCAST"      # 厂商

    def call_by_5g(self):
        print("父类的5g通话")

class MyPhone(Phone):
    procer = "ITHEIMA"       # 复写父类属性

    def call_by_5g(self):    # 复写父类方法
        print("子类的5g通话")
```

一旦复写父类成员，那么类对象调用成员的时候，就会调用复写后的新成员，如果需要使用被复写的父类的成员，需要特殊的调用方式

- 调用父类成员

```
使用成员变量：父类名.成员变量
使用成员方法：父类名.成员方法(self)
```

- 使用super()调用父类成员

```
使用成员变量：super().成员变量
使用成员方法：super().成员方法()


```

**示例**

```
class Phone:
    producer = "ITCAST"

    def call_by_5g(self):
        print("父类的5g通话")

class MyPhone(Phone):
    producer = "ITHEIMA"   # 注意拼写，这才是复写

    def call_by_5g(self):
        print("子类的5g通话")

    def show_parent_producer(self):
        print(super().producer)   # 方法内部才能用 super()

phone = MyPhone()
print(phone.producer)              # ITHEIMA
phone.show_parent_producer()       # ITCAST
```


容器类型详细注解

```
my_list: list[int] = [1, 2, 3]
my_tuple: tuple[str, int, bool] = ("itheima", 666, True)
my_set: set[int] = {1, 2, 3}
my_dict: dict[str, int] = {"itheima": 666}
```

注意：

- 元组类型设置类型详细注解，**需要将每一个元素都标记出来**
- 字典类型设置类型详细注解，需要2个类型，第一个是key，第二个是value

>  我更建议使用在注释中进行类型注解，看起来更美观

注释中进行类型注解：

```
class Student:
	pass
var_1 = random.randint(1, 10)   # type: int
var_2 = json.loads(data)   # type: dict[str, int]
var_3 = func()   # type: Student
```

> 一般无法直接看出变量类型的时候再添加类型注解

#### 9.7.2   函数（方法）的类型注解

```
def fuc(data):
	data.app
```

如上所示：

- 在编写函数（方法），使用形参data的时候，工具没有任何提示
- 在调用函数（方法），传入参数的时候，工具无法提示参数类型

这些都是因为，我们在定义函数（方法）的时候，没有给形参进行注解

函数和方法的形参类型注解语法：

```
def 函数方法名(形参名: 类型, 形参名: 类型,.......):
    pass
```

同时，函数（方法）的返回值也是可以添加类型注解的

```
def 函数方法名(形参: 类型,......., 形参: 类型) -> 返回值类型:
    pass
```

#### 9.7.3   Union类型

```
my_list = [1, 2, "itcast", "itheima"]
my_dict ={"name": "周杰轮", "age": 31}
```

> 遇到如上情况你怎么办？常规的类型注释能应付两个不同的数据类型杂糅到一起吗？

这个时候我们就可以使用union

```
my_list: list[Union[int, str]] = [1, 2, "itcast", "itheima"]

def func(data: Union[int, str]) -> Union[int, str]:
    pass
```

**切记一定要在开头引用from typing import Union**

### 9.8   多态

多态，指的是：多种状态，即完成某个行为时，使用不同的对象会得到不同的状态

```
class Animal:
    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        print("汪汪汪")

class Cat(Animal):
    def speak(self):
        print("喵喵喵")
        
def make_noise(animal: Animal):
    animal.speak()

dog = Dog()
cat = cat()

make_noise(dog)       # 输出：汪汪汪
make_noise(cat)       # 输出：喵喵喵
```

**重点是思路，同一种行为（动物叫声），传入不同的对象（动物种类），产生的结果也不一样**

**多态常运用在继承上**

- 父类
- 子类复写父类的成员方法
- 定义新的函数传入父类对象（实则传入子类对象）

**抽象类又是一个什么玩意？**

来看一下父类定义的成员方法：

```
class Animal:
    def speak(self):
        pass
```

**这是个空实现**，这种设计的含义是，让父类确定有哪些方法，具体方法实现让子类来定义

这种写法就叫**抽象类（也可以称之为接口）**
