> - 认识 IPA 音标系统，理解音标、音节和重音符号。
> - 区分几组容易混淆的元音和辅音。
> - 初步理解英语单词重音和弱读。

### 第一堂课：认识英语音标（15分钟）

**1. 什么是IPA**

IPA = International Phonetic Alphabet，即国际音标

它是用于记录语音的符号系统，英语单词的拼写和发音并非一一对应，因此不能单纯依靠字母拼写判断读音

例如：

| 单词  | 音标（简化美式标注） |
| :---: | :------------------: |
|  cat  |        /kæt/         |
| ship  |        /ʃɪp/         |
| sheep |        /ʃiːp/        |
| think |        /θɪŋk/        |

你需要掌握三个概念：

- Phoneme：音位，能够区分词义的语音单位

> 注释：是不是觉得这个概念很抽象？反正我第一次读这句话实在是摸不着头脑
>
> **Phoneme（音位）就是：能够让一个单词变成另一个单词的声音区别**
>
> 看一个非常经典的例子，Cat（猫）和Bat（蝙蝠/球棒）
>
> 我们把 Cat 拆成三个声音：
>
> - /k/：第一个声音
> - /æ/：中间的元音
> - /t/：最后一个声音
>
> Bat 也是三个声音：
>
> - /b/
> - /æ/
> - /t/
>
> 两者唯一的区别就是第一个音，这里的 /k/ 和 /b/ 就是两个不同的 Phonemes（音位）
>
> **这就是音位最重要的特征：改变一个音位，可能改变整个单词的意思**

- Stress：重音，发音中突出某个音节的现象
- Syllable：音节，单词发音中的节奏单位

**2. 学会看音标符号**

| 符号  |     作用     |       示例       |
| :---: | :----------: | :--------------: |
| `/ /` | 表示音标转写 |     `/kæt/`      |
|  `ˈ`  |    主重音    |   `/ˈsen.../`    |
|  `ˌ`  |    次重音    | 单词中的次级突出 |
|  `ː`  |  表示长元音  |      `/iː/`      |
|  `.`  |   音节分界   |  `/ˈsen.trəl/`   |

**今天要特别记住：`ˈ` 放在音节前面，表示后面的音节需要重读**

### 第二堂课：元音训练（30分钟）

今天重点练习三组元音对比

#### 第一组：**/iː/ 与 /ɪ/**

**sheep**（`/ʃiːp/`）绵羊

**ship**（`/ʃɪp/`）船

发音区别：

- `/iː/`：舌位较高，嘴角略向两侧展开，声音相对紧一些
- `/ɪ/`：舌位稍低，口腔更放松，声音通常更短。

练习：

`sheep → ship → sheep → ship`

连续练习 10 组，注意不要把两个音读成一样

#### 第二组：**/e/ 与 /æ/**

**bed**（`/bed/`）床

**bad**（`/bæd/`）坏的

`/æ/` 通常需要更大的下巴开度，不能把它读成普通的 `/e/`

> 注释：
>
> | 英语元音 | 英式传统标注 | 美式传统标注 |
> | :------: | :----------: | :----------: |
> |  DRESS   |     /e/      |     /ɛ/      |

练习：

`bed → bad → bed → bad`

#### 第三组：**/ʊ/ 与 /uː/**

|  短语  |  音标   | 意思 |
| :----: | :-----: | :--: |
|  book  |  /bʊk/  |  书  |
|  food  | /fuːd/  | 食物 |
|  good  |  /ɡʊd/  | 好的 |
| school | /skuːl/ | 学校 |

> 注释：
>
> | 英语元音 | 英式传统标注 | 美式传统标注 |
> | :------: | :----------: | :----------: |
> |  shoot   |     /uː/     |     /u/      |

练习：

`book → food → good → school`

**本堂课验收：** 能够听出以上三组声音存在差异，并且能够模仿词典音频读出这些单词

### 第三堂课：**辅音训练（25 分钟）**

今天重点学习三个发音对比

#### 1. **/θ/ 与 /ð/**

- `/θ/`：清齿间摩擦音，发音时声带不振动
- `/ð/`：浊齿间摩擦音，发音时声带振动

具体练习：

| 单词  |  音标  | 练习重点 |
| :---: | :----: | :------: |
| think | /θɪŋk/ |   清音   |
| thank | /θæŋk/ |   清音   |
| this  | /ðɪs/  |   浊音   |
| that  | /ðæt/  |   浊音   |

练习时把舌尖轻放在上下牙之间，轻轻送气

#### 2. **/v/ 与 /w/**

|  /v/  |  /w/  |
| :---: | :---: |
| very  |  wet  |
| voice | water |
| vest  | west  |

`/v/`：上齿轻触下唇，并让声带振动

`/w/`：双唇收圆，然后快速展开，不要用牙齿咬住嘴唇

#### 3. **今天的辅音验收**

尝试连续读三遍：

Think about this.

This is very important.

We work with water.

重点检查：

- think 的第一个音
- this 的第一个音
- very 与 water 的第一个音

不要急着追求速度，首先保证发音部位正确

### 第四堂课：**单词重音与弱读（20 分钟）**

这部分会直接影响你读计算机英文论文、听技术讲座的能力

#### 1. **什么是单词重音？**

看两个词：

- `central`：/ˈsen.trəl/
- `computer`：美式发音中重音落在第二音节

读的时候不能把每个音节都念得一样重

练习：

- CEN-tral
- com-PU-ter
- SE-cu-ri-ty

#### 2. **什么是 Schwa？/ə/**

`/ə/` 是英语中非常常见的弱读元音

例如：

- about：/əˈbaʊt/
- central：/ˈsen.trəl/

它通常出现在非重读音节中，发音比较轻、比较放松

观看 BBC 的相关教学：

https://feeds.bbci.co.uk/learningenglish/english/features/pronunciation

BBC 的发音课程包含 schwa、弱读和自然口语发音等内容

今日任务：听三遍，跟读五遍，尝试找到单词中发音最轻的部分

### 第五堂课：今天的词汇积累**（25 分钟）**

今天只学习 8 个词。目标不是背很多，而是学会正确记忆一个英文单词

|   单词   |    核心含义    |  重音提示   |
| :------: | :------------: | :---------: |
| central  | 中心的，核心的 |  CEN-tral   |
|  system  |      系统      |   SYS-tem   |
| security |  安全，安全性  | se-CUR-i-ty |
| network  |      网络      |  NET-work   |
|   data   |      数据      |    DA-ta    |
|  access  | 访问，访问权限 |   AC-cess   |
| protect  |      保护      |  pro-TECT   |
| research |      研究      |  RE-search  |

**重点搭配**

- central role：核心作用
- computer system：计算机系统
- network security：网络安全
- sensitive data：敏感数据
- unauthorized access：未经授权的访问
- protect information：保护信息
- security research：安全研究

今天每个单词采用下面的方法：

1. 在 Cambridge Dictionary 搜索单词
2. 选择 US 发音，听两遍
3. 看 IPA，找到主重音
4. 自己跟读 3～5 次
5. 记住一个核心释义和一个常见搭配

**今天的词汇笔记示范：**

**security**

- 词性：noun
- 核心含义：安全；安全性
- 搭配：network security
- 例句：Network security is important.
- 网络安全很重要

今天不要求你记住一个单词的所有词典释义，只要求掌握它在当前语境中的用法
